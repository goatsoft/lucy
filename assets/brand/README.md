# Lucy brand

Lucy, the mascot, and everything made from her. Decisions in
[ADR 0013](../../docs/adr/0013-brand-and-type.md).

| Folder | What |
|---|---|
| `source/` | The original renders: `Lucy.webp` (portrait), `Lucy-Masthead.webp` (head) |
| `fonts/` | Fredoka and Nunito variable fonts (SIL OFL, licences alongside) |
| `dist/` | Everything generated by `build.py`; do not edit by hand |

```sh
python3 -m venv /tmp/lucy-brand && /tmp/lucy-brand/bin/pip install pillow fonttools vtracer
/tmp/lucy-brand/bin/python assets/brand/build.py --site   # --no-trace skips the slow SVG traces
```

## What's in dist

| File | Use |
|---|---|
| `icon-1024.png`, `icon-512.png`, `icon-192.png` | App icons (rounded corners, transparent outside) |
| `icon-maskable-512.png` | Android / PWA maskable icon (full bleed, 80% safe zone) |
| `apple-touch-icon.png` | iOS home screen (opaque square; iOS rounds it) |
| `favicon.ico`, `favicon-16/32/48.png` | Browser tabs |
| `roblox-icon-512.png` | Roblox experience icon (full bleed; Roblox rounds it) |
| `roblox-thumbnail-1920x1080.png` | Roblox experience thumbnail |
| `og.png` | Social preview, 1200x630 |
| `logo-lockup.png` / `logo-lockup-ink.png` | Lucy and the wordmark, for dark / light grounds |
| `wordmark.svg`, `wordmark-white.svg`, `wordmark-ink.svg` | The wordmark as paths (no font needed) |
| `lucy-portrait.*`, `lucy-head.*` | The mascot with linework restored (PNG, WebP, 256 px WebP, traced SVG) |
| `fonts/` | Static Fredoka SemiBold and Nunito SemiBold instances used by the build |

## Colours

Sampled from the art: magenta `#f03ede`, orchid `#c050ea`, violet `#8757e2`,
sky `#5bd0f8`, night `#2b0f57` to `#0e0822`. The wordmark gradient runs
magenta, orchid, violet, sky.

## Type

- Display: **Fredoka** (Roblox: `FredokaOne`)
- Text: **Nunito** (Roblox: `Nunito`)
